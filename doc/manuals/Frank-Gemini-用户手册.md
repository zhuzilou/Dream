# Frank Gemini 用户手册 (V1.2)

Frank Gemini 是面向股市小白的 A 股投研陪练型智能体。

它不是荐股机器人，也不会替你做最终买入、卖出和仓位决策。Frank 的目标是帮你把口语化问题翻译成可分析的问题，再用行情、板块、资金、成交量和技术位置生成观察条件、触发条件、失效条件和复盘结论。

## 1. 某只股票能不能买

可以直接问：

- `上海电力最近一直在跌，可以买入吗？`
- `xx 股票能买吗？`
- `xx 现在能不能买？`
- `分析下 xx 的走势，是否有合适买入点`
- `分析 600021`

Frank 会进入“个股买入决策与观察计划”，输出：

- 问题订正。
- 结论先行。
- 真实数据依据。
- 触发条件。
- 失效条件。
- 仓位纪律。
- 观察 checklist。
- 关键术语解释。

Frank 不会只回答“可以买”或“不能买”。更合适的结论通常是“可观察”“等待确认”“可轻仓试错”“回避”或“暂不满足买入条件”。

## 2. 收盘后有哪些板块值得关注

可以直接问：

- `最近有哪些板块值得关注？`
- `有什么股票值得关注？`
- `我不知道接下来该看什么`
- `收盘后帮我看方向`
- `选股`
- `推荐一些股票`
- `买什么`

Frank 会进入“板块观察池与教学复盘”。

注意：这是观察池，不是买入名单。场景二只负责缩小研究范围，每只候选股票仍需要进入场景一继续判断。

盘中提问时，Frank 会输出“盘中临时观察版”，并提示数据仍在变化、置信度降低，收盘后需要重新生成正式观察池。

## 3. 查看和复盘观察池

可以使用：

- `查看观察池`
- `最近观察池`
- `复盘观察池`
- `复盘观察池 1`

Observation Memory 记录的是某次板块观察任务的结构化结果，不等于旧的 `watchlist`。

复盘不是证明 Frank “推荐对了”，而是检查观察条件是否成立，例如是否守住前低、是否缩量企稳、是否放量站回关键均线、是否出现一日游。

## 4. 记录或查看待补充术语

可以使用：

- `记录术语 放量修复 场景7.1`
- `待补充术语`
- `术语记录`
- `导出术语记录`

当 Frank 无法解释某个术语，或你认为某个术语应补充到某个场景中，可以显式记录到 Term Learning Queue，供后续产品升级。

## 5. 管理 watchlist 和持仓池

旧的手动关注能力仍保留，但和 V1.2 Observation Memory 分开：

- `监控 上海电力`：加入长期手动关注的 `watchlist`。
- `池子`：查看 `watchlist` 和持仓池。
- `买入 股票名称 价格 数量`：登记持仓。
- `卖出 股票名称 数量`：记录减仓或移除持仓。
- `持仓分析`：对已有持仓做辅助分析。

`watchlist` 是长期手动关注池；Observation Memory 是某次板块观察任务的结构化记录。两者可以关联，但不会自动混用。

## 已降级功能

以下功能不再作为 V1.2 主流程：

- 定时新闻直接推送。
- 回复消息触发的 RiskAuditor 审核。

原因是单条新闻和快速变化的市场数据很容易制造噪声。V1.2 会把新闻作为辅助材料，而不是直接把新闻推送给你当作买卖依据。

## 投资须知

Frank 的所有输出都只用于辅助决策。真正的买入、卖出和仓位控制始终由你完成。

更好的提问方式不是“能不能买”，而是：

```text
这只股票当前是否出现低风险买点？如果没有，应等待哪些触发条件和失效条件？
```
